# منظومة الإشراف والتوجيه — Google Sheets + GitHub Pages

## 1) قاعدة البيانات على Google Drive
1. ارفع `برنامج_الدوام_الموحد_-_المدارس_الشرعية.xlsx` و`الموجهون_جاهز_للرفع.xlsx` إلى Drive ← افتحهما بـ Google Sheets ← ملف ← حفظ كجدول بيانات Google.
2. في كل ملف: **ملف ← مشاركة ← النشر على الويب** ← اختر الورقة (الجدول: «قالب جدول الحصص»، والموجهون: «الموجهون») ← الصيغة **CSV** ← نشر. انسخ الرابط.
3. الصق الرابطين في `config.js` (`SCHEDULE_CSV` و`SUPERVISORS_CSV`).
> التعديل في Google Sheets يظهر في الموقع بعد دقائق (تأخير النشر) وإعادة تحميل الصفحة.
> الورقة المنشورة تصبح قابلة للقراءة لكل من يملك الرابط؛ لا تضع فيها بيانات حساسة غير لازمة (أرقام الهواتف مثلاً).

## 2) الواجهة على GitHub
أنشئ مستودعاً، ارفع `index.html` و`config.js` و`data-loader.js`، ثم Settings ← Pages ← Deploy from branch ← main / root.

## ملاحظات
- عمود «الجنس» في ملف الموجهين خمّنتُه من الأسماء، راجعه.
- مدرستان لا يدل اسمهما على الجنس (النعمانية، الخسروية) تُعامَلان «ذكور» حتى تحدد جنسهما في `SCHOOL_GENDER_OVERRIDES`.
- يوحّد التحميل تلقائياً صيغ الأيام والحصص والصفوف المختلفة في الملف؛ بقي بعض الصفوف بأسماء شعب خاصة أو بلا صف فتظهر بتسميتها الأصلية.
- المدارس تُستخرج من ورقة الجدول؛ المنطقة والتخصص المطلوب لكل مدرسة قيم افتراضية.
